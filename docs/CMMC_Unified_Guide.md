# CMMC 2.0 Level 2 Unified Adjudication & Evidence Guide

This guide provides a comprehensive, all-in-one reference for all 110 NIST SP 800-171 controls, combining the plain-English adjudication questions with concrete examples of the evidence required to prove satisfaction.
