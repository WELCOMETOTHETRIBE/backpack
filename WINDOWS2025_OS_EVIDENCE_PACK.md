# Windows Server 2025 — CMMC L2 “OS Evidence Pack” (Class A, Missing Evidence)

Input source: `SCTM_FULL_STATUS_LIST.csv`  
Scope filter enforced for this pack:
- `classification == "System-Enforced (Class A)"`
- `pilot_status == "Planned / Partially Evidenced"`

This pack is **validation-only** (read-only). It provides **repeatable CLI and GUI validation artifacts** an assessor can verify.

## How to generate the evidence bundle

Run the collector (creates `evidence/<RunId>/...` and `evidence/evidence-<RunId>.zip` by default):

```powershell
PowerShell -ExecutionPolicy Bypass -File .\tools\collect_windows2025_cmmc_evidence.ps1 -OutDir C:\Evidence
```

## Common context artifacts (collected once per run)

The script always captures these (assessor-friendly) baselines:
- `evidence/<RunId>/_context/context-summary.txt`
- `evidence/<RunId>/_context/secpol.cfg` (from `secedit /export`)
- `evidence/<RunId>/_context/gpresult/gpresult-computer.txt` (best-effort)
- `evidence/<RunId>/manifest.txt`
- `evidence/<RunId>/hashes.sha256.txt`
