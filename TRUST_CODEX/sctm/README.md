# System Control Traceability Matrix (SCTM) — Pilot (GUI editable)

This folder contains a **pilot SCTM** that is:
- **Auditable**: includes verbatim NIST SP 800-171 Rev.2 requirement text and guidance (as provided by the governance bundle SCTM template).
- **User-friendly**: includes a **single-file GUI editor** that runs locally with no install.
- **Productizable**: SCTM data is stored in JSON, exportable to CSV, and can be version-controlled.

## Files

- `sctm-data.json`: canonical SCTM dataset (110 controls) generated by merging:
  - verbatim Rev.2 text + guidance from the governance bundle SCTM template
  - pilot control mapping classification and justification
  - pilot evidence index references
  - pilot implementation plan summaries
- `SCTM_GUI.html`: single-file GUI editor with the dataset embedded (works via `file://`).

## How to use the GUI editor

1. Open `SCTM_GUI.html` in a browser (Edge works well on Windows).
2. Use search/filters to find a control.
3. Click a row to open the editor drawer.
4. Edit:
   - Pilot status
   - Owner role
   - POA&M ID
   - Review dates
   - Notes
5. Click **Save changes** (saved to browser local storage).
6. Click **Export JSON** to create an assessment-ready artifact you can store in the evidence vault and/or commit to version control.

## Deployment to the Windows VM

Recommended VM path:
- `C:\SCTM\SCTM_GUI.html`

Open:
- `file:///C:/SCTM/SCTM_GUI.html`

## Canonical CSV and auditor-defensible columns

- **Pipeline source of truth**: `tables/SCTM_FULL_STATUS_LIST.csv` (used by CI, closeout generator, validators).
- That CSV includes **auditor-defensible** columns per control: **evidence_location**, **evidence_regeneration**, **auditor_requirement**. These are synced from `tables/evidence-index.json` by running `tools/enrich_sctm_with_auditor_requirements.py` (run after evidence index changes).

## Scope and non-claims

- This SCTM is anchored to **NIST SP 800-171 Rev.2** (CMMC 2.0 Level 2).
- NIST SP 800-171 Rev.3 is referenced only as explanatory context: `https://doi.org/10.6028/NIST.SP.800-171r3`.
- Editing the SCTM is governance activity; exported snapshots should be retained as evidence artifacts.
