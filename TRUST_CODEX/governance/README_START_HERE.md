# Governance bundle (embedded in Trust Codex)

This folder contains **platform-agnostic template** governance documents that support CMMC Level 2 / NIST SP 800-171 Rev.2 closeout.

## Important
- These documents are **templates** and **must be tailored** to your environment.
- These documents are **governance artifacts**; they are not technical evidence by themselves.

## Contents
- `GOVERNANCE_BUNDLE_INDEX.md` — the “start here” index for policies, SOPs, plans, and forms included with this Codex manual.
- `platform-agnostic/` — template documents, preserved under their original paths.
