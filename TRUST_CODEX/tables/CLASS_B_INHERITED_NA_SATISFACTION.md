# Class B / Inherited / Not Applicable — Satisfaction Statements (per control)

This table provides assessor-safe, per-control statements for requirements that are **not** classified as System-Enforced (Class A).

**Rules**:
- Governance artifacts are **not** treated as technical evidence.
- Inherited controls are explicitly bounded (provider vs MacTech responsibilities).
- N/A determinations are tied to the **pilot boundary** and must be re-evaluated on boundary change.

Rev.3 is referenced as explanatory context: [NIST SP 800-171 Rev.3 (May 2024)](https://doi.org/10.6028/NIST.SP.800-171r3).
