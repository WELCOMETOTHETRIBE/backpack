# Start Here — CMMC Accelerator onboarding

This manual is a **CMMC Level 2 (NIST SP 800-171 Rev.2)** accelerator. It helps you generate, retain, and adjudicate evidence on cadence.

**Important**: This is not a pre-validated system. The **system owner/customer is the Attestee**.

- You run the bulk collectors to generate evidence under `C:\evidence`.
- You ingest runs into the manual to link artifacts to controls.
- You run audit enforcement to keep claims accurate.
- You review and sign governance (Policies/SOPs + records) and maintain annual/change-control refresh.

## Start here (recommended)

From the Dashboard, click **CMMC Accelerator onboarding**. The wizard explains:

- the requirement set (NIST 800-171 Rev.2)
- what the VM produces as evidence
- strict ingest/adjudication rules
- audit reports and how to use them
- Attestee identity (required)
- governance program maintenance
- export and retention expectations

## Definitions (quick)

- **Adjudicated**: you reviewed the basis and verified the required evidence exists, is accessible, and integrity-protected.
- **Outstanding**: requires closeout actions and/or adjudication.
